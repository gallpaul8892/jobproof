# Spec T-003m: Accessibility and large text

Ticket: [tickets/T-003m-accessibility-and-large-text.md](../tickets/T-003m-accessibility-and-large-text.md).
Package E. Kind: **mobile only**. NFR-9, NFR-11.

## Questions and assumptions

- A1. Volume key as shutter: yes, through a small local Expo module (below). If it cannot be
  finished without a device to test on, the ticket records it as a deviation and ships without
  it; TalkBack and touch targets are not optional.
- A2. Dark mode: the app keeps its light theme (white surfaces, company primary) and opts out of
  forced dark (`userInterfaceStyle: "light"`), which guarantees legibility; a dark theme is later.

## Summary

Large text, touch targets, TalkBack labels and announcements, not-colour-alone statuses,
reduced motion, and the volume-key shutter.

## Patterns

None. Shared UI primitives (`src/ui/Button`, `StatusBadge`, `CheckRow`) carry the rules once.

## Data / API / Backend / Shared / Web

None. Theme contrast reuses `shared/src/branding/contrast.ts` (the server already rejects themes
under 4.5:1).

## Mobile

- Text: no fixed heights on text containers; `allowFontScaling` left on; `numberOfLines` only on
  list titles (3) with the full title in `accessibilityLabel`; layouts tested at `fontScale` 2.0.
- Touch targets: `src/ui` enforces `minHeight` 48 (all) and 56 (primary: Take photo, Submit
  report, Sync now, shutter, checklist rows) and `hitSlop`; spacing 8 dp between adjacent
  targets.
- TalkBack: job rows one element, label "Repaint lounge, hall and landing, BS6 5QA, in progress,
  6 of 9 done", role button; thumbnails "Before photo, taken 08:14, sent" (+ caption); checklist
  `accessibilityRole="checkbox"` with `accessibilityState.checked`; sync line in an
  `accessibilityLiveRegion="polite"` and `AccessibilityInfo.announceForAccessibility` on change
  ("3 photos sent"); errors next to fields and announced; no toast-only messages.
- Statuses: icon + word (+ colour) everywhere (`StatusBadge`).
- Reduced motion: `AccessibilityInfo.isReduceMotionEnabled()` disables non-essential animation.
- Volume shutter: `mobile/modules/volume-shutter` (Expo Modules API, Kotlin): while the camera
  screen is focused, the activity's `dispatchKeyEvent` for `KEYCODE_VOLUME_DOWN/UP` emits an event
  and consumes it; disabled elsewhere. Shutter labelled "Take photo".
