# Spec T-003d: Job detail and checklist (read-only)

Ticket: [tickets/T-003d-job-detail-and-checklist.md](../tickets/T-003d-job-detail-and-checklist.md).
Package B. Design section 6. Kind: backend then mobile. Q11.

## Questions and assumptions

- A1. Operatives never see prices, quotes, customer email or billing address (ticket default).
- A2. Contact = `customers.contact_name` if set, else `customers.name`; phone = `customers.phone`.

## Summary

`GET /operative/jobs/{id}` and the detail properties (`notes`, `contact`, `checklist`,
`report`) on `OperativeJob`, plus the read-only job screen.

## Patterns

None.

## Data

None (0010 already has everything).

## API

`getOperativeJob` and the `x-ticket: T-003d` properties of `OperativeJob` (also in the list).
`report` is null until a draft exists; the draft and submitted fields shown here are read-only
(`submitted_at`, `submitted_by`, `review_status`, `reviewed_at`, `reviewed_by`). Remove `T-003d`
from `PENDING_TICKETS`.

## Backend

- `operative_jobs.build_job(job)`: checklist = job items not removed (by `position`) with status
  and note from the report item if any, then removed items that have operative data (status not
  open, a note, or a photo) with `removed: true`.
- Response schema test: walk the JSON of every operative operation and fail on any key in
  {`manager_notes`, `email`, `billing_address`, `total_pence`, `quote`, `invoice`, `payments`}.
- Any job of the caller, any date and status (needed after reinstall, T-003j 8); others 404.

## Shared

`useOperativeJob(id)` with `initialData` from the list cache.

## Web

None.

## Mobile

`app/(app)/jobs/[jobId]/index.tsx` (read-only parts; capture and ticking come in T-003e/f):
- Reference, job type label, scheduled date, site address (tap → `Linking.openURL` with
  `geo:0,0?q=<encoded address>`, which offers installed maps apps), notes collapsed to 6 lines
  with "Show more", contact name and phone (tap → `tel:` URL, which opens the dialler filled, not
  dialling).
- Checklist list with "0 of 9 done"; no checklist → "No checklist for this job. You can still
  take photos and submit."
- Submitted → "Submitted 14:12" (and "Reviewed by Sarah Whitfield" when reviewed); no capture
  controls.
- 404 → "This job isn't available." then back to the list.
- Offline → shows cached detail with "Offline"; never blank. Unseen job offline → "This job's
  details weren't saved. Connect once to load it." (T-003i 7).
- Pull to refresh updates notes; local ticks (T-003f) live in SQLite and are untouched.

## Infra / local

None. `AndroidManifest` `<queries>` for `tel:` and `geo:` intents (Android 11 package
visibility) via `app.config.ts` `android.intentFilters`/config plugin if `Linking.canOpenURL`
needs it.
