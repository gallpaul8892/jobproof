# Spec T-003o: Customer sign-off or note (optional, deferrable)

Ticket: [tickets/T-003o-customer-sign-off.md](../tickets/T-003o-customer-sign-off.md). Package F.
**First to cut if the pilot is late**: everything here is additive (own migration, own contract
items), so cutting it leaves no trace. Kind: backend + mobile + web. P9, Q9.

## Questions and assumptions

- A1. No drawn signature; "has concerns" is highlighted on the report, no notification.
- A2. The sign-off belongs to the report, is set in the draft and frozen at submission.

## Summary

A typed customer sign-off (outcome, name, note, time) saved with the draft, shown to the manager.

## Patterns

None.

## Data

Migration `0013_sign_off` (down_revision `0012`): enum `sign_off_outcome` (`present_happy`,
`present_concerns`, `not_present`); `job_reports.sign_off_outcome` null,
`sign_off_customer_name` text null, `sign_off_note` text null, `sign_off_recorded_at` timestamptz
null. Checks: outcome null ⇒ the other three null; outcome not null ⇒ `recorded_at` not null;
`present_*` ⇒ name not null; `not_present` ⇒ name null. Downgrade drops.

## API

`DraftUpdate.sign_off`, `OperativeReport.sign_off`, `ReportDetail.sign_off` (`SignOff` schema).
Remove `T-003o` from `PENDING_TICKETS`.

## Backend

`drafts.apply_draft_update`: `sign_off` object sets all four fields, `null` clears; name
single-line rule (trim, 1 to 120, "Enter the customer's name." when blank for present
outcomes), note multi-line rule (500); 422 `loc ["body","sign_off","customer_name"]`.
Submission freezes it (no write path after submission). Manager report builder emits it.

## Shared

`operative/validation.ts` `validateSignOff`; `operative/status.ts` sign-off sentence
("Customer present, happy: A. Patel, 14:05"); the submit summary uses it ("customer sign-off:
none" when null).

## Web

Report detail: a "Customer sign-off" panel; `present_concerns` uses the warning style (icon +
word "Concerns"); not present shows "Customer not present, 14:05".

## Mobile

`sign-off.tsx` from the job screen: three outcome buttons, name field (hidden for "not present"),
note, the line "This records what the customer told you. It is not a signature."; saved locally
(`drafts.sign_off_json`, `sign_off_rev`) and synced like other draft fields; read-only after
submission.
